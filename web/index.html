Como interpretar as medições
O aquecimento e as amostras rodam dentro do C. Compilar e abrir o processo ficam fora do tempo por execução. Os dados são reutilizados e tendem a estar em cache. O programa materializa as etapas em arrays; a medição inclui esse trabalho e não prevê tokens por segundo do Colibri.
TSC significa Time Stamp Counter: contador de referência. Seus ticks não são os ciclos efetivos do núcleo. O contador de ciclos da PMU, Performance Monitoring Unit, só aparece se o Linux permitir. O aplicativo não altera permissões do sistema.
Afinidade mantém o processo em uma CPU lógica. O sistema ainda pode interrompê-lo. Veja a variação entre amostras; o custo do loop vazio é medido separadamente, sem subtração automática.

A roda do mouse aproxima ou afasta mantendo o ponto sob o cursor. Arraste o fundo, use o botão do meio, ou segure Espaço para navegar. “Enquadrar” mostra uma visão geral; “Focar seleção” aproxima o contexto escolhido.

Todos os valores
Os blocos mostram os vetores completos. Se quiser uma visão estrutural, desligue “Dados nos blocos”; os valores continuam acessíveis no inspetor. Clique em um elemento para ver decimal, bits, bytes e suas posições lógicas.
O desenho dos grupos mostra quantos números cabem em 128 ou 256 bits. É um agrupamento didático, não uma captura de registradores físicos.
Três comparações diferentes
Meu circuito: resultado das suas conexões. Gabarito: conta independente com a regra escolhida. C no Xeon: resultado do código compilado.
C e simulação concordarem mostra que o programa seguiu seu circuito. Só a comparação com o gabarito e outros casos avalia se o circuito resolve a conta pretendida.
Precisão e representação
FP32 é ponto flutuante de 32 bits: sinal, expoente e fração. int8 é inteiro com sinal de 8 bits; uint8 é inteiro sem sinal. Dois códigos int4 cabem em um byte.
FMA, Fused Multiply-Add, funde multiplicação e soma com um único arredondamento. Quantização e mudanças na ordem das somas podem alterar o resultado. ULP, Unit in the Last Place, mede a distância entre FP32 adjacentes.
Os exemplos estudam um grupo de 64 pesos. Não representam uma camada inteira do Colibri, o arranjo matricial R16, GPU, cache ou paralelismo. SIMD significa Single Instruction, Multiple Data; SSE significa Streaming SIMD Extensions; AVX significa Advanced Vector Extensions.
